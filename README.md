# 飄帶隨風 🎏

把照片上的飄帶變成隨風飄動的動畫，純前端 PWA，無需安裝、可離線使用。

## 功能
- 載入任意照片，點選飄帶固定端（錨點）
- 用筆刷塗出飄帶範圍（遮罩），只有飄帶會動
- 可調幅度、速度、波長、風力、明暗
- 錄製 6 秒影片（mp4 / webm）下載
- 離線可用，可加入主畫面

## 部署（GitHub Pages）
Settings → Pages → Branch 選 `main` / `(root)`，網址：`https://kftseng2oo1.github.io/ribbon/`

## 安裝到 iPhone
用 Safari 開啟網址 → 分享 → **加入主畫面**。

## 更新注意
修改程式後請把 `sw.js` 內的 `VERSION` 加一，已安裝的裝置才會更新快取。
